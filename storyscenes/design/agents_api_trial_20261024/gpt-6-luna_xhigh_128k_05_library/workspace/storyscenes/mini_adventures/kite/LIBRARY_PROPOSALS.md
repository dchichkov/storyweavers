# Concrete library proposal

For a real neighbourhood branch adapting this activity, keep the book trolley in a clearly marked returns bay and make a floor-level picture-book return tray available beside it. That gives children a safe, supervised way to help sort low books without moving a staff trolley into public walkways.

Keep high shelves staff-only for children’s activities. A staff member should inspect and hold any step ladder, direct the reach, and stop the search if a foot rocks or the floor is uneven. The story’s ladder parameter represents that ordinary safety check; it is not permission for a child to climb alone.

A small, dated reshelving note at the circulation desk could distinguish current shelf locations from stale catalogue entries. Staff should still confirm the location rather than treating the note as authority. The proposal requires no software integration: a paper note, a marked trolley bay, and an adult-supervised floor-level activity are sufficient.
