# The Boat at Willow Pond

An offline, standard-library-only adventure. Mara borrows a long-handled net to help Jules retrieve his toy boat. Both children remain on the bank in every state and every local action.

## Run it

From the repository root:

```bash
python -m storyscenes.mini_adventures.kite.world --seed 0 --scenes 8
python -m storyscenes.mini_adventures.kite.world --seed 14 --scenes 7 --params '{"net_reach_cm":190,"boat_distance_cm":130,"net_mesh":"intact","wind":"calm","weeds":false}'
python -m unittest storyscenes.mini_adventures.kite.test_world
```

`--params` is a JSON object of overrides to the seeded parameters. The generator supports exactly seven or eight scenes. Six scenes are core; `remember_boat` and `read_reeds` are optional vignettes, so a seven-scene route contains one and an eight-scene route contains both. Paths are searched with a seeded, bounded search; rejected branches are never narrated or committed.

The Python interface is `Parameters`, `parameters(seed)`, `initial(params)`, `validate(state)`, `SCENES`, `guard(scene_id, state)`, `play_scene(params, state, scene_id)`, `generate(seed=0, *, count=8, params=None)`, and `replay(params, path)`. Every episode records detached before/after states and atomic equality requirements and changes. The story is the episode text joined with two newlines.

## Explicit ending recipes

The following paths are deliberately listed so the outcome does not depend on which optional vignette the seeded search happens to select. They can be run in a Python shell from the repository root:

```python
from storyscenes.mini_adventures.kite.world import Parameters, replay

recovered = Parameters(net_reach_cm=190, boat_distance_cm=130,
                       net_mesh='intact', wind='calm', weeds=False)
recovered_path = ('spot_boat', 'remember_boat', 'borrow_net', 'bank_plan',
                  'cast_net', 'return_net', 'ending_boat_home')
assert replay(recovered, recovered_path)[-1]['after']['story.outcome'] == 'boat_recovered'

safe_loss = Parameters(net_reach_cm=90, boat_distance_cm=190,
                       net_mesh='intact', wind='calm', weeds=False)
safe_loss_path = ('spot_boat', 'remember_boat', 'borrow_net', 'bank_plan',
                  'cast_net', 'return_net', 'ending_boat_left')
assert replay(safe_loss, safe_loss_path)[-1]['after']['story.outcome'] == 'boat_left_in_pond'
```

The success recipe has enough reach, sound mesh and clear water. The safe-loss recipe makes the boat farther away than the net’s safe reach; the children use the net to measure rather than lean into the pond. Other physical ways to reach the complete loss ending include gusty wind, torn mesh, or an unobserved reed tangle. For a paired reed counterfactual, use `weeds=True`, an intact net, calm wind and sufficient reach: a route containing `read_reeds` can retrieve the boat through the observed gap; replacing it with `remember_boat` leaves the obstructed cast unsuccessful. Both endings return the borrowed net.

## State and limits

The five validated parameters are net reach (60–240 cm), boat distance (60–240 cm), mesh condition (`intact` or `torn`), wind (`calm`, `breezy`, or `gusty`), and whether reeds obstruct the approach. A ten-centimetre margin is reserved for a safe reach. Breezy weather permits a wait for a lull; gusty weather blocks casting. The reed observation is consequential when reeds are present. State validation enforces bank locations, net custody, boat location, attempt completion and ending consistency.

This is a small authored play, not a hydrodynamics model. The dimensions are simple scenario thresholds; no risk is simulated beyond those explicit rules. Each scene has authored local prose rather than a general language model. Routes vary through observations, physical conditions and resulting actions, not name substitution or whole-story templates. The reference story is preserved independently and is not generated by the simulator.
