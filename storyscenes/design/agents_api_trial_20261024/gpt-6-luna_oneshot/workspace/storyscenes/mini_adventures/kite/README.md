# The Borrowed Reel

A standard-library-only, offline kite-workshop adventure. Run from the repository root:

```sh
python -m storyscenes.mini_adventures.kite.world --seed 0 --scenes 8
python -m unittest storyscenes.mini_adventures.kite.test_world
python check_pack.py .
```

`Parameters` accepts `wind` (0 calm, 1 gentle, 2 gusty), `reel_sound` (whether the borrowed reel's string is sound), `shy` (whether Ivo needs the low-pressure invitation), `spare_line` (whether Mr Vale has replacement line), and `name` (the inviting child). Example: `Parameters(wind=2, reel_sound=False, shy=True, spare_line=True)` produces a reported fault and can still allow a later shared flight if the wind is flyable. `Parameters(wind=0, reel_sound=False, spare_line=False)` produces a grounded-together ending. `Parameters(wind=2, reel_sound=True)` permits the sound-reel flight. These are parameter recipes, not guaranteed route strings; seeded selection determines whether an optional vignette appears.

The executable encounter IDs are listed in `scene_inventory.json`; `ribbon_vignette` and `wind_vignette` are optional. The reference inventory consolidates twenty beats into the compact playable scenes. State and events are generated from atomic `LocalPlay` actions. A seven-scene route uses the six required beats plus one optional slot is not supported by the current selector; see limitations below.

## Endings and limitations

The intended outcomes are `shared_flight` (the reel/line and wind permit safe flight) and `grounded_together` (flight is not safe or available, but the children finish together and the borrowed reel is returned). A faulty borrowed reel is returned and reported; it is never silently cut or made useless. The story is deliberately small and the physical model is symbolic: gust level and a sound/frayed boolean stand in for detailed weather and line mechanics. `shy` is validated for the public interface but current prose treats Ivo gently in either case. Story text is scene-authored, not generated by an LLM.
