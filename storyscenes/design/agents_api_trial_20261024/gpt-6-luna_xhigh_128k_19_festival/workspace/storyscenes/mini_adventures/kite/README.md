# The Line Between Us

A standard-library-only, offline mini-adventure set at a village welcome festival. Leni borrows Mrs Bell’s spool of string and works with new neighbor Jo to hang bunting at a safe, reachable height. The executable pack is new; the `kite` directory name is only the isolated harness path.

## Run and replay

From the repository root:

```bash
python -m storyscenes.mini_adventures.kite.world --seed 0 --scenes 8
python -m storyscenes.mini_adventures.kite.world --seed 41 --scenes 7
python -m unittest storyscenes.mini_adventures.kite.test_world
```

The command prints the selected prose. `generate(seed, count=7 or 8, params=...)` returns a JSON-native trace; `replay(params, path)` reproduces each scene’s state, event trace, and text. The local play actions use the shared `LocalPlay` helper. Scene search is seeded, bounded, and speculative branches are never included in the returned path or trace.

## Explicit ending recipes

These recipes work for either supported length. Optional scenes can be present in an eight-scene route, but do not change the selected ending in these examples.

```python
from storyscenes.mini_adventures.kite.world import Parameters, generate

# Calm, dry, sturdy square posts; enough string; Jo can reach; knot holds.
square = Parameters(spool_length_cm=240, gusty=False, rainy=False,
                    posts_sturdy=True, jo_reach_cm=70, knot_slips=False)
row = generate(0, count=7, params=square)
assert row['final_state']['story.outcome'] == 'shared_square'

# Rain makes the exposed square unsuitable, so the completed welcome is sheltered.
hall = Parameters(spool_length_cm=180, gusty=False, rainy=True,
                  posts_sturdy=True, jo_reach_cm=70, knot_slips=False)
row = generate(0, count=8, params=hall)
assert row['final_state']['story.outcome'] == 'sheltered_hall'
```

A slippery knot, short spool, gusts, rain, unstable posts, or insufficient reach also selects the hall. When the hall is used, its low rail provides a safe alternative; an insecure knot is reinforced with a rail hitch in an enacted local action. `knot_vignette` can instead practice a double loop before the layout decision. It consumes ten centimetres and can make the square line feasible when other conditions allow it. `color_vignette` is an optional, persistent design choice from Jo. Seven-scene stories omit both optional vignettes; eight-scene stories include exactly one.

## State and outcomes

The six validated parameters are spool length, gusts, rain, post stability, Jo’s reach, and whether the string slips. They change the physical actions available and/or the ending. Leni and Jo remain at the selected festival location; the basket moves with them; the hung bunting stays on its actual line; the spool remains Mrs Bell’s property; and used plus remaining string is conserved. Both endings require an opened festival and the returned spool. `shared_square` finishes at the safe outdoor low line. `sheltered_hall` finishes a complete welcome under cover rather than leaving it as a future plan.

Every scene has a state-changing local action. Omitted scenes do not execute effects. `LocalPlay` validates each candidate before committing it, so a failed local action does not mutate the caller or its existing trace.

## Limits

This is a small scenario model, not general physics: wind, knot reliability, reach, post stability, and string length are simplified into explicit constraints. The setting has two display locations and two endings; the children do not split up, scenes cannot repeat, and crowd behavior is only represented where it changes the welcome. Prose is authored per scene and conditioned on enacted outcomes, not generated by an LLM. Mechanical tests cannot establish literary quality.
