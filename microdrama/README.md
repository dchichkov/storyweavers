# Compositional Microdrama

A standalone, classical proof of concept: **The Palace That Learned to Read**.
It adapts the supplied G. Wolf / Three Little Pigs / Story Fox fable into a small
executable world. Different conditions produce a library, a secret night school,
or a palace whose books remain locked away.

Follow-on: [two Sol 6.1 authors produced new story-worlds](authoring_trial_20261024/README.md)
under a fixed contract, with independent checking and documented repairs.
The [revised authoring prompt](AUTHORING_PROMPT_V2.md) is ready for another trial.

Start with [the library story](examples/library/story.txt), then compare
[the night school](examples/night_school/story.txt) and
[the locked palace](examples/locked/story.txt). Each directory also contains the
complete trace, twelve grounded questions, and a short follow-up conversation.
The stories are generated by Python; their paragraphs are authored performances
selected from committed events. No model, network, or third-party package runs.

## Run it

Python 3.9 or later, from the repository root:

```bash
python3 -m microdrama --qa
python3 -m microdrama --work separate --attention 2 --qa
python3 -m microdrama --access locked
python3 -m microdrama --attention 4
python3 -m microdrama --attention 2 --no-mentor
python3 -m microdrama --witness --seed 3 --out /tmp/microdrama-example
python3 -m microdrama --qa --chat
python3 -m unittest microdrama.test_microdrama -v
python3 -m microdrama.audit
```

The folder can be copied alone to another parent directory; run the same module
commands from that parent. It imports no sibling experiments and needs no data
files outside this folder. `--out` writes `story.txt`, `trace.json`, and `qa.json`.
The audit command regenerates saved examples, unfiltered samples, conversations,
and `audit.json`. Neither command changes the existing engines.

## The experiment

The physical world records that wind, mud, and weak foundations broke the houses.
People and paper carry a different story blaming Wolf. Repetition spreads that
story without rewriting the material facts. Fox exploits the pigs' concern for
status to bring books into the valley. Those books are carriers with locations,
owners, access conditions, and content that can be read with divided attention.

Reading supplies partial understanding. Teaching supplies reinforcement. Building
and testing a drain or bridge establishes a skill. Successful joint practice also
builds shared experience. The response to the removal order is computed from
those accumulated states; the director never receives a requested ending.

| Change one condition | Result in this authored world |
|---|---|
| Open shelves → locked cupboards | Reading and practical trials disappear; the library cannot form. |
| Shared work → separate jobs, with half attention and teaching | Mira succeeds, Tansy does not; a rescued book supports a night school. |
| Teaching available → unavailable, with half attention | Neither trial succeeds; books are locked away. |
| Full attention → one-quarter attention | A brief demonstration cannot compensate; both trials fail. |
| Mira misses the theft → Mira witnesses it | Her belief changes; the pigs' accusation and institutional outcome do not automatically change. |

These are consequences of explicit fictional rules, not evidence about real
learning or political change. `audit.json` contains the matched state differences.

## What is composed

There are three layers:

1. **World operations.** Move, embed, transmit, observe, test, and change custody.
   Every action runs in a private transaction. Invalid effects leave neither state
   nor event history behind. A whole multi-action encounter also rolls back.
2. **Microdramas.** Each has an admission condition, local actions, a priority,
   and a practice name. The scheduler selects an eligible encounter, executes it,
   and records which alternatives were available. Reading binds different books
   and readers; practical trials bind a worker, object, and craft. Learning scenes
   can interleave with lunch and propaganda. Some optional scenes never occur.
3. **Telling and questions.** Pure rendering uses historical episode snapshots.
   Paragraphs point to committed event IDs. Questions query the same snapshots
   and carry exact `(event, key, value)` evidence. A conservative reader view
   exposes facts only after the corresponding encounter has been fully read.

The ten-encounter opening spine is deliberately authored in order. The local
learning encounters and resulting settlement provide the experiment's
compositional variation. Seed changes mostly alter encounter order and optional
scenes; they are **not** additional plot diversity. This is one fable with three
institutional outcomes, not an open-domain story generator.

## Memetics implemented here

`Memeplex.atom(...)`, `+`, `+=`, and `/` compose and dilute weighted content.
Content has no effect until embedded in a declared physical carrier. A book
cannot transmit while locked or remote. A person may hold a false accusation
while the world preserves the actual cause. Encounters accumulate their effects
in physical participants rather than in a free-floating narrator.

The deliberately visible numerical policy is: books contribute craft strength
`2 / attention`; a brief demonstration contributes `0.75`. At `1.5` understanding,
the worker chooses an adequate construction. Its dimensions must then pass the
physical test. Success adds `2.5` protection of books and reduces obedience by
`1.5`; successful shared work adds `1` shared experience to each helper. A skilled
character objects if `protection + shared experience - obedience >= 1`. Both
objectors need shared experience to coordinate. The newspaper adds `0.5`
obedience when that optional encounter occurs. These are authoring parameters.

The full `story.py` north star remains larger: this prototype uses one content
type for concept/story atoms but keeps executable actions as a separate type.
It does not yet make arbitrary nested characters, concepts, and whole plots
interchangeable executable memeplexes. It demonstrates physical embedding and
state-dependent compatibility without claiming to finish that algebra.

## Sources of the design

All implementation and adaptation prose here are new. The research systems
provided design ideas; their code and story text have not been copied.

| Source | Concrete borrowing | Boundary |
|---|---|---|
| `story.py` / gen6 | Physical carriers, weighted content, composition, attention division | Only a small explicit content vocabulary; no general kernel parser |
| Storypatches | Exact preconditions, atomic changes, fingerprints, provenance | Structured-state patches; no patching English after generation |
| StoryScenes | Scene admission, persistent state, meaningful counterfactuals | A fixed large-scale story scaffold remains |
| StoryWorlds | Physical affordances, character state, grounded QA | No general MUD or unrestricted action language |
| [Alabaster](https://emshort.blog/2009/12/10/moods-in-conversation/) | Fact gates and contextual follow-ups | Twelve question patterns and two follow-up forms |
| [Versu](https://cs.uky.edu/~sgware/reading/papers/evans2014versu.pdf) | Social situations offer actions; character state selects responses | Explicit local policies, not a recreated autonomous-agent architecture |
| [Counterfeit Monkey](https://emshort.blog/2013/01/24/making-of-counterfeit-monkey-puzzles-and-toys/) | Reusable operations plus a curated world and physical prerequisites | No arbitrary object invention |
| [STORYBOOK](https://intellimedia.ncsu.edu/wp-content/uploads/sites/42/npg-ijcai01.pdf) | Paragraph-scale expression and connected discourse | Authored paragraphs, not its linguistic realization system |
| [Curveship](https://nickm.com/curveship/) | Separate events from their telling | One narrative voice; no arbitrary retelling or focalization |

## Evidence and limits

`test_microdrama.py` checks rollback, transmission, observation, replay,
counterfactuals, physical trials, historical narration, and question grounding.
The finite-grid gate covers all **48 input combinations × seeds 0–4**. Saved
unfiltered samples use a fixed parameter-selection seed of 777 and generation
seeds 0–4. `REVIEW.md` distinguishes manual reading from mechanical checks.

Replay verifies exact state changes and hashes. Its dependency edges identify
previous writers of read state, not a complete causal theory. The evidence
bundle is an audit record, not protection against a hostile editor recomputing
hashes. Reader exposure annotations are authored, not automatically proven from
English. The question interface accepts the twelve displayed questions (or their
short topic IDs), `Why?`, and `What happened next?`; other inputs fail closed.

Incidental gestures and background crowds are literary texture. The model tracks
the consequential cast, ownership, access, learning, accusations, and outcomes;
it does not simulate every noun in the prose. Physical locations are coarse and
time advances by encounters. The three ruling pigs are one group entity.

The strongest current result is that knowledge access, individual competence,
shared experience, and public control can diverge while producing readable
consequences. Mass parallel authoring, integration cost, cross-fable reuse, and
usefulness as model-training data remain untested. See `TODO.md` for the next
experiments and `DESIGN.md` for the original acceptance checklist.

## Adding a microdrama

Declare any new carrier and state fields in the initial schema. Define a
`Microdrama(id, admits, perform, priority, practice)`; its `perform` function uses
`world.act(...)` and transaction operations. Add a renderer using only that
episode's before/after state, and annotate consequential facts exposed by it.
Add question rules if it introduces a new question topic. Include a rejected
prerequisite case, a consequential counterfactual, and a read-through of its
neighbors. An admitted action must change state; an incomplete encounter fails
atomically. Duplicate IDs are rejected.

See `read_book(child, book)` and `practice(child, prop, craft)` for the current
reusable bindings. The rebinding test makes Mira read the bridge book and checks
that bridge knowledge, rather than drain knowledge, is transferred. This shows
operation reuse; publishing that new story variant would also require a matching
discourse plan. There is no claim that new logic automatically writes its prose.
