# Next experiments

- Measure a fixed extension task: add a fourth clue with two tiers, a topic beat,
  an emotionally compatible refusal and re-entry, and an ending consequence.
  Record authoring and repair minutes separately from engine work. Preserve first
  outputs and all failed checks. Compare agent-assisted and human-only authoring
  against the same acceptance criteria before discussing a cost multiplier.
- Predeclare a held-out set of action sequences, including abrupt topic changes,
  late disclosure, repeated offenses, and attempts to repair trust. Grade complete
  transcripts blind to condition; report contradiction, repetitive dialogue,
  weak turn, and unearned outcome separately from mechanical test success.
- Replace the once-per-evening social-action memory with contextual memory tied
  to a particular offense or disclosure. Gate: a new offense can receive a new
  apology, while repetition about the same offense cannot farm trust.
- Broaden the repair route without weakening causality. Gate: at least three
  meaningfully different successful strategies, including one that doesn't use
  both `reflect` commands. The random policy currently never discovers repair;
  this is evidence of a narrow authored solution, not proof of impossibility.
- Add more state-specific emotional variants. Current shared reaction lines
  repeat between characters, and re-entry text may feel mechanical. Gate:
  independent readers find no tonal reversal in a predeclared 30-session set.
- Explore composable social practices or memeplex objects only after a second
  independently authored drama exposes concrete reusable needs. Preserve the
  carrier-based knowledge and effect trace; avoid inference from English text.
- Consider a browser interface and richer input only after the dramatic model
  earns the complexity. Real-time interruption, gist points, concurrent behaviors,
  and natural-language understanding remain outside this prototype.
