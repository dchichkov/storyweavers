# Remaining work

- Run the controlled extension trial in `AUTHORING.md`, with an independent
  reader and a human-only baseline. The current task has not measured a labor
  multiplier, and text scenes are not equivalent to Façade's production units.
- Model promises as commitments that can be revised or withdrawn in conversation.
  Current accepted practical commitments persist; the evening ends before their
  real-world fulfillment. Do not claim that a promised refund already happened.
- Improve emotional alternatives in sympathetic memory scenes. High anger can
  still coexist with a gentle memory too easily. Gate: no unexplained tonal
  reversal in a predeclared set of complete conversations judged by readers.
- Add a way to repair a breached confidence through later conduct. At present
  betrayal reliably changes the ending and an apology cannot erase it, but there
  is no route to earn back that boundary within this one evening.
- Expand contextual acknowledgments. Repeated successful interventions can still
  trigger the same generic response, even though they do not farm state.
- Track partial hints and uncertain interpretations as knowledge. The model
  distinguishes public/private full truths and several background facts, but not
  degrees of belief or conflicting accounts.
- Extend spontaneous character initiative beyond the current readiness rules.
  These are explicit authored conditions, not autonomous psychological planning.
- Add concurrent actions, timing, and gist-aware interruptions only after a
  second drama justifies them. Current joint exchanges are atomic and turn-based.
- Audit accessible focus management and responsive layout on more devices. The
  local browser player has keyboard-visible focus, semantic controls, and a
  stacked small-screen layout, but has not had an independent accessibility review.
