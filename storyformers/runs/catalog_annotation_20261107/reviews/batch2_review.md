# Batch 2 review and v3 release

All six stories, 09_market through 14_pond, are accepted after complete story
reviews and verification of corrections. They contain 4,628 words. The cumulative
run has 14 structurally valid stories / 10,931 words, zero validation errors and
no conflicting extension definitions. Across those stories 485 distinct canonical
fields are used; this is vocabulary coverage, not an annotation density target.

The independent reports are batch2_root_09.md, batch2_independent_10_11.md,
batch2_independent_12.md, batch2_root_13.md and batch2_independent_14.md. Each
records the actual source/annotation review and semantic findings separately from
machine shape/type/link checks. All six feedback files were reviewed.

Corrections preserve complete negative utterances, requested prohibitions and
conditional consequences instead of accidentally linking their positive operator
targets. Content links retain spoken need/knowledge but remove unspoken outer
says/thinks wrappers. Other fixes separate capacity from occurrence, measured
quantity from an instrument reading, specific quantified objects from generic
kinds, imperative subjects from speakers, and spatial extent from frequency.

The annotations preserve unresolved source transitions and identities: an
unreported lantern handoff, pottery construction/schedule/layout gaps, selection
from two pears, a costume disk handoff and a twig's later placement. No invented
transition is used to make endpoints agree. Actual deformation, possible breakage
and later intactness retain separate phases.

The released prompts/annotate_v3.md incorporates these lessons, seven concrete
corrected examples in batch2_examples_v3.json, and the unchanged six-definition
extension_registry_v3.json. Each example includes the current annotation hash
and referenced entity/event/proposition/scope records. The full 1,024-item catalog
and historical examples remain available. Ergonomic fit is retained as a possible
future vocabulary improvement, not accepted solely from one story. Edibility
uses the existing affordance_eating meaning.

Batch 3 may now start under v3. A renewed simultaneous capacity test still
permits three workers plus root; six-story logical batches use successive waves.
Sequentially created probes replacing completed workers do not establish six
concurrent workers. No external model/API calls were made for this annotation.
