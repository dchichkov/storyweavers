# Annotation prompt revisions

- **v0 — two pilots:** established lossless word records, the 1,024-field sparse
  vocabulary, explicit IDs/scopes/evidence, and locally generated nonwords and
  positions. Preflight revisions fixed participant IDs, multiple event bindings,
  status conventions and contextual lemma policy. Frozen with reviewed pilots.
- **v1 — batch 1, stories 03–08:** incorporates corrected pilot examples and five
  shared extension definitions. Separates attitude from content, negated desire
  from avoidance, actor from syntactic subject, event from event mention, and
  physical representation from fictional identity. Adds restricted-emptiness,
  appearance/material, source-continuity and within-bundle status guidance.

- **v2 — batch 2, stories 09–14:** all six v1 stories reviewed and corrected.
  Adds positive content under negation, whole-utterance polarity, information
  goals, inherited quotation attribution, actual attitude versus false content,
  precise audiences/roles, scoped consent, source gaps, and wire-format checks.
  Adds six corrected batch examples and the accepted `affordance_supporting`
  extension. Retains the full catalog, prior examples, and prior five extensions.

- **v3 — batch 3, stories 15–20:** all six v2 stories reviewed and corrected.
  Adds complete conditional/negative/request content, content-arrow checks,
  capacities versus actual events, instrument readings versus quantity claims,
  bounded distribution, catalog-meaning checks and endpoint/source-gap guidance.
  Adds seven reviewed examples. Keeps the same six provisional extensions;
  ergonomic fit remains feedback rather than a new accepted field.

- **v4 — final revision after batch 3, stories 15–20:** all six v3 stories
  reviewed and corrected. Adds eight reviewed examples covering desired absence,
  inverse loan perspectives, actual versus directional/completed actions,
  attributed speech and modal content, time-qualified group membership, rejected
  reasons and artifact symbolism. Specifies normalized lexical auxiliary labels
  for future annotations; earlier examples remain frozen. Admits the seventh
  provisional extension, `symbolic_reference`. The canonical catalog remains at
  1,024 fields. All 20 stories retain their original authoring prompt versions.

Each revision was released only after its preceding annotations and feedback had
been reviewed. V4 is the reusable final prompt; no story is relabeled as authored
under it. The bounded final consistency corrections to stories 12–13 preserve
the prior reviewed snapshots used by frozen examples.
