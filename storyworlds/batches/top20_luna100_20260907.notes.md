# Matched Luna vs Mini: Top-20 References

## Results

Luna produced stronger judged stories and more confirmed quality-qualified worlds
for lower cost, but its end-to-end execution yield was worse. This is a result
on the selected workload, not a general claim about the models.

| Metric | Mini | Luna |
| --- | ---: | ---: |
| Generation attempts / materialized | 100 / 100 | 100 / 100 |
| Raw ten-sample runnable | 69 | 73 |
| Accepted general repairs | 8 | 3 |
| Accepted import-only repairs | 54 | 75 |
| Sample command succeeds after repair | 88 | 81 |
| Sample command + verification | 72 | 66 |
| Full count + standalone + replay + verification | 65 | 54 |
| Valid judged worlds / eligible | 72 / 72 | 64 / 66 |
| Valid judged stories | 715 | 633 |
| Mean quality /9, equal weight per judged world | 5.8167 | 6.4594 |

| Confirmed worlds with mean quality >=6 | 35 | 48 |
| Strict local checks plus mean quality >=6 | 32 | 39 |

| Generation returned-usage cost | $1.2088 | $0.4062 |
| Judging returned-usage cost | $0.7813 | $0.7305 |
| Total returned-usage cost | $1.9901 | $1.1367 |

The generation requests had identical input-token totals (948,435) and similar
output totals (477,471 Mini, 479,395 Luna). All 100 Luna generation responses
reported `completed` and Flex; all 66 judge responses also reported completed
and Flex. Costs include the two invalid judge responses, and are usage-based
estimates, not invoice reconciliation. No API or local sampling timeouts occurred.

Two Luna judge responses omitted an input ID from their plot-group partition:
`repaired_069/mechanism` omitted `s000131`, and `repaired_041/bacon` omitted
`s000576`. Both supplied ten individual story ratings, but the unchanged protocol
rejects the whole result when the partition is invalid. Their raw responses are
retained, not manually rewritten or resubmitted. Both worlds pass strict local
checks, so Luna's confirmed strict-plus-Q count is 39, potentially 39-41 once
those two are validly rated. The full geometric composite is **withheld**, not
zero. Its `usable_samples: 0` is an uncomputed placeholder, not an empty corpus.

Luna has longer stories and higher ten-story semantic diversity, but the raw
LZMA ratio does not show a broad improvement: both corpora remain extremely
compressible. Corpus length, returned pool size, and surviving worlds differ,
so the raw ratio is not a controlled estimate of narrative variety by itself.
The two invalid judge results prevent a full geometric-score comparison.

Among the 48 known quality-qualified Luna worlds, there are 43,953 returned
stories and 41,719 exact-unique stories. This excludes the two unrated worlds
and is retained separately in `qc/known_qualified_pool.json`; it is not an
imputed full-batch score. Sixteen successful samplers underfilled their 1,000-row
request, compared with ten for Mini. Missing rows were not padded or retried.

### Remaining Defects

Luna has 19 final runtime failures: ten syntax errors, three missing dataclass
fields, two missing keys, and one each for an undefined name, missing world
method, non-JSON-serializable set, and import failure. A further 15 runnable
worlds fail verification. Three general repairs were accepted, including one
that downgraded StoryError guards. The 75 accepted import-only repairs are
environment fixes, not proof of story or QA correctness.

The full per-reference table is in the [Luna report](top20_luna100_20260907.report.md).
Mini's [report](top20_mini100_20260907.report.md) and archive were left intact.
The unchanged StoryWorld test suite passed all 112 tests before the live run.

## Manual Review

Read 14 story outputs from seven Luna worlds, including QA for six stories.
Also inspected the runtime failure of the eighth targeted world. Selection
included the same four reference/task cases used for Mini's QA spot check, then
high-, low-, repetitive-, and higher-diversity judge examples. This targeted,
non-blind review is qualitative, not a measured corpus-wide defect rate.

The first two returned samples were checked for these paired QA cases:

| Reference / task prefix | Observation |
| --- | --- |
| `garnet` / `terminate` | More coherent than Mini's bridge/rooftop drift: dust blocks a beacon, or ice hides a usable bridge cable. Dialogue and internal decisions connect to the repair. Some QA still gives details not fully stated in the prose, and "Mara solved it when Mara..." is awkward. |
| `repaired_013` / `mechanism` | No samples: undefined `setting` in `_story_lines`. This is a generation failure, not a zero-quality story rating. No manual fix was introduced to improve the comparison. |
| `repaired_007` / `parade` | Lantern rescue and returned-light ending are coherent; the inspected QA uses the right branch, unlike Mini's shoe/banner mismatch. Answers still contain "They helped by the sailor rescued..." and generic twist language. The 192-row pool is underfilled and repeats nearly identical stories. |
| `repaired_012` / `parade` | The fog welcome and missing-flag signal stories have different problems and solutions. QA stays on the rendered branch by reproducing its selected plot paragraphs. This avoids Mini's wrong clue, though it is largely restatement rather than rich world-state QA. |

The first two saved judge-input stories were then read for these cases:

| Reference / task prefix | Q /9 | D /9 | Manual interpretation |
| --- | ---: | ---: | --- |
| `repaired_069` / `parade` | 8.0 | 3 | A specific lost-drum problem leads to a practical rescue. The rating is generous: a supposedly broken part becoming a sewn keepsake is not established by the drum-rescue branch, and a colors/flags ending can feel transplanted. Still substantially more readable than malformed low-scoring outputs. |
| `repaired_081` / `terminate` | 8.0 | 0 | A considerate containment/rescue story, but repeated nearly word for word with names and locations changed. The separate zero diversity rating correctly distinguishes readable prose from useful variation. |
| `repaired_098` / `bacon` | 3.9 | 3 | Name leakage (Luna/Bramble inside a Pip/Tess story), sentence fragments, and "They the cook removed" expose broken template joins. The low score is warranted; Luna has not eliminated Mini's failure classes. |
| `repaired_013` / `historic` | 7.7 | 5 | Rope-and-lever access, rebuilt friendly signals, and other problems give materially different developments. Some endings remain fragments: "By sunset, the blue shutter gleaming...". The relative diversity score is plausible, without treating the pool as hundreds of independent plots. |

The judge is blind to the generator name in its input: it receives the shared
calibration and story text, not model labels, scripts, or QA. Manual review is
not blind and does not change the recorded ratings. Story quality, semantic
diversity, execution reliability, and QA grounding remain distinct checks.

## Plan

This run repeats the Mini run's 20 references and five task seeds per reference
(100 generated worlds), changing only the generation model and output paths.
All 100 request bodies were compared before submission after normalizing those
two differences. The matching evidence is retained in `matched_requests.json`.

- Luna trial: `top20_luna100_20260907`, generator `gpt-5.6-luna`.
- Mini comparison: `top20_mini100_20260907`, generator `gpt-5.4-mini`.
- References: `storyworlds/reference_sets/luna_top20_20260907.json`, one example
  per request, with current hashes verified against the selected manifest.
- Seeds: 2026091800-2026091804, repeated across all 20 reference arms.
- Both: Flex, reasoning `none`, concurrency 50, source emission, 32,000 output
  cap, current v12 base prompt, no addendum, 900-second API timeout.
- Both: four local audit workers, 1,000 requested samples per generated world,
  general repair then import-only repair, verification, full-count/standalone/
  deterministic-replay checks, and retained compressed sample pools.
- Both: Terra/Flex/none judge, up to ten uniformly selected positions per
  eligible world, unchanged judge prompt and geometric score, no judge retries.
- All 20 source references passed fresh 100-sample/verify/replay preflights.
  Current generation/audit/scoring dependencies matched the Mini snapshots.
- No prompt, canonical reference, repair, or scoring rule changes in this run.

The matched design controls task descriptions and reference files, not the
stochastic generation itself. A given sample seed need not represent the same
story or variation in two different generated programs. We reuse Mini's saved
judge results instead of charging for a new Mini evaluation.

Report conditional quality/diversity for each model and for common judged
source/task pairs. Also report yield and strict quality-qualified counts over
all 100 attempts. Do not assign a numeric quality to unjudged failures. These
100 pairs share only five unique task descriptions and 20 selected references;
they are not 100 independent task draws. This is a descriptive comparison on
this selected workload, not a general model benchmark or proof of QA correctness.

## Retention and Cost

Trial data: `storyworlds/batches/prompt_trials/top20_luna100_20260907/`.
Generated sources: `storyworlds/worlds/prompt_trials/top20_luna100_20260907/`.
Keep frozen requests, response/attempt ledgers, raw and repaired source,
rejected repair attempts, sample pools, judge evidence, and runtime snapshots.
Wrap long phases with `caffeinate -is` to avoid sleep-interrupted API calls.

Pre-run estimate: $0.4646-0.4907 generation and $1.4600-1.5850 judging if all
100 worlds qualify; $1.9246-2.0757 total. Assumptions are 6,000 generation output,
5,000 judge input, and 1,600 judge output tokens per request. This is not a hard
spend cap; the capped-output scenario is $5.0757 at the assumed input sizes.
Saved returned usage is reported separately after completion.

## Commands

Preparation used the existing `prompt_trials.prepare` API with these
CLI-equivalent arguments, after preflight and source-hash checks:

```bash
./.venv/bin/python storyworlds/prompt_trials.py prepare top20_luna100_20260907 \
  --seed 2026091800 \
  --example-manifest storyworlds/reference_sets/luna_top20_20260907.json \
  --per-example 5 --model gpt-5.6-luna --reasoning-effort none \
  --concurrency 50 --local-samples 1000
```

Before generation, the JSON save helper added `local_workers=4`,
`compress_samples=true`, `compact_checks=true`,
`large_batch_protocol="reference_batch_v1"`, and
`matched_trial="top20_mini100_20260907"` to `trial.json`.
Preflight, matched-request evidence, and budget were also saved. Frozen requests
were not edited after preparation, and the completed Mini data was not changed.

```bash
OPENAI_API_KEY="$(cat .API_KEY)" OPENAI_BASE_URL=https://api.openai.com/v1 \
```
