# Top-20 Mini Confirmation Run

## Frozen Plan

- Generator: `gpt-5.4-mini`, Flex, reasoning `none`, source emission,
  32,000 output-token cap, API concurrency 50, request timeout 900 seconds.
- References: `storyworlds/reference_sets/luna_top20_20260907.json`;
  20 examples, one per request, five matched tasks each (100 requests total).
- Numeric generation seeds: 2026091800 through 2026091804. The same five
  task descriptions are used in every reference arm, with distinct output paths.
- Current base prompt, no supplementary addendum. Canonical registry unchanged.
- Judge: `gpt-5.6-terra`, Flex, reasoning `none`, up to ten uniformly selected
  positions from each eligible returned sample pool. No judge retries.
- Local protocol: four workers; 1,000 requested samples/world; general repair,
  verification, standalone CLI, hash-seed replay, then import-path-only repair.
  No new repair rules or manual story corrections are introduced for this run.
- All reference hashes matched the selected manifest. All 20 references passed
  verification, 100-sample generation, and deterministic replay before API use.
- Each long-running command is protected with `caffeinate -is` on this Mac.

Trial data: `storyworlds/batches/prompt_trials/top20_mini100_20260907/`.
Materialized scripts: `storyworlds/worlds/prompt_trials/top20_mini100_20260907/`.
Frozen requests, responses, preflight evidence, original/repaired sources,
compressed sample pools, judge inputs/responses, and runtime snapshots are kept.

## Cost Estimate

Before generation: $1.7422 generation plus $1.4600-1.5850 judging if all worlds
qualify, or $3.2022-3.3272 total. This assumes 6,000 generation output tokens,
5,000 judge input tokens, and 1,600 judge output tokens/request. It is not a
spending cap; capped output lengths would instead give an estimated $10.6172.
Transport retries and unknown outcomes can add cost.

Mini's [model page](https://developers.openai.com/api/docs/models/gpt-5.4-mini)
lists standard input/cache-read/output prices of $0.75/$0.075/$4.50 per million
tokens. [Flex processing](https://developers.openai.com/api/docs/guides/flex-processing)
uses Batch rates: the estimator uses $0.375/$0.0375/$2.25 for Mini, without a
separate cache-write premium. Terra retains the existing recorded Flex rates.
The budget and actual returned-usage accounting are saved separately.

## Interpretation

This is a fresh evaluation of references selected from the earlier Luna run,
not a matched Mini-versus-Luna model comparison. The old run used disjoint
tasks, 106 references, and different corpus size. Selecting the top 20 introduces
selection bias; five matched tasks per arm still give noisy reference rankings.
Quality and semantic diversity are conditional on valid judge results. Report
all-attempt execution/strict-pass yields alongside those means. The existing
geometric dataset score is unchanged, and ten-story semantic diversity remains
a separate diagnostic. Neither repair success nor story judging certifies QA.

## Results

All 100 generation requests returned completed responses and materialized code.
Raw ten-sample execution passed for 69. Eight general repairs and 54 import-only
repairs were accepted (these counts can overlap). Afterwards, 88 sample commands
succeeded, 72 also passed verification, and 65 passed full count, standalone
execution, and deterministic replay as well. Six remaining scripts have syntax
errors despite completed, non-truncated API responses. Other failures include
missing keys, character-distinctness constraints, ASP/verification defects, and
unrepaired imports. There were no sample timeouts in this run.

All 72 eligible judge calls succeeded. Terra rated 715 stories: 71 ten-story
sets and one five-story set. Equal-weighted world quality is 5.8167/9, and
semantic diversity is 2.3889/9 (story-weighted quality is 5.8168/9).
35 worlds meet the existing mean-quality floor of 6; 32 also meet the strict
local gate. Of those, 19 additionally reach semantic diversity >=3.

Returned-usage cost: $1.2088 generation plus $0.7813 judging = **$1.9901**.
All 172 returned API responses have priced usage; all reported Flex. These
figures are token-cost estimates, not invoice reconciliation.

This confirms the important scope limitation: the Terra protocol sees only
stories. Its quality score cannot certify the QA pairs or the correctness of
the simulated world. In particular, selecting sources solely by readable prose
would retain some scripts with wrong-branch QA. Import repairs do not address
that, and six of the eight accepted general repairs weakened StoryError guards;
those need semantic review before curated training use.
